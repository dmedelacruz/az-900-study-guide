# AZ-900 Study Guide

An interactive, whitepaper-style web application for studying the Microsoft Azure Fundamentals (AZ-900) certification exam.

## Features

- Covers 100% of AZ-900 exam objectives
- Clean, whitepaper-like reading experience
- Interactive quizzes and flashcards
- Client-side progress tracking
- Fully static — no backend required

## Tech Stack

- **Astro** — static site generator
- **Tailwind CSS** — utility-first styling
- **MDX** — markdown with interactive components
- **Vanilla JS** — lightweight interactivity via Astro islands
- **GitHub Pages** — deployment

## Getting Started

```bash
npm install
npm run dev
```
