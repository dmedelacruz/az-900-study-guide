## What is Cloud Computing?

<KeyTerm term="Cloud computing">The delivery of computing services — including servers, storage, databases, networking, software, analytics, and intelligence — over the internet, on demand, with pay-as-you-go pricing.</KeyTerm> is one of the most transformative shifts in modern technology. Instead of buying, owning, and maintaining physical servers and data center infrastructure, organizations rent access to everything from computing power to storage from a cloud provider like Microsoft Azure.

Think of it like the electricity grid. You don't build your own power plant to turn on the lights — you simply plug into the grid and pay for the electricity you consume. Cloud computing works the same way: you connect to a vast pool of computing resources over the internet and pay only for what you use.

This model has evolved over decades. In the early days of computing, organizations relied on massive **mainframes** — single, powerful machines shared by many users. The 1990s brought the **client-server** era, where dedicated servers in on-premises data centers served desktop applications across local networks. Cloud computing represents the next leap: computing resources delivered as a utility over the internet, available to anyone, anywhere, at any scale.

<Callout type="info">
Microsoft Azure operates in more than 60 regions worldwide, spanning over 140 countries — making it one of the largest global cloud infrastructures. This global footprint allows organizations to deploy services close to their users for lower latency and better compliance with data residency requirements.
</Callout>

## Five Essential Characteristics (NIST SP 800-145)

The National Institute of Standards and Technology (NIST) defines five essential characteristics that distinguish true cloud computing from traditional hosted or managed services. If a service meets all five, it qualifies as cloud computing.

**On-demand self-service** — You can provision computing resources (such as virtual machines, storage, or databases) whenever you need them, without requiring human interaction with the service provider. In Azure, you can spin up a new virtual machine through the Azure Portal in just a few minutes — no phone calls, no support tickets, no waiting.

**Broad network access** — Cloud resources are available over the network and accessible through standard mechanisms from a wide variety of devices. Whether you're on a laptop in the office, a tablet at home, or a phone on the train, you can reach your cloud dashboard and manage your resources.

**Resource pooling** — The cloud provider's computing resources are pooled together to serve multiple customers simultaneously using a <KeyTerm term="multi-tenant model">An architecture where multiple customers (tenants) share the same physical infrastructure, with each tenant's data and workloads logically isolated from the others.</KeyTerm>. Multiple organizations' workloads run side by side on the same physical hardware, but each customer's data remains isolated and invisible to others. This pooling is what allows cloud providers to achieve massive economies of scale.

**Rapid elasticity** — Cloud resources can be elastically provisioned and released — sometimes automatically — to scale rapidly outward or inward with demand. Picture an e-commerce site on Black Friday: traffic surges tenfold, additional servers spin up automatically to handle the load, and when the rush ends, those servers scale back down. You only pay for the peak capacity while you actually need it.

**Measured service** — Cloud systems automatically monitor, control, and report resource usage transparently for both the provider and the customer. Think of it like a water meter: you can see exactly how many gigabytes of storage you used, how many hours your virtual machines ran, and how much network bandwidth you consumed. This metering is the foundation of the pay-per-use pricing model.

<DeepDive title="The Full NIST Definition of Cloud Computing">
NIST Special Publication 800-145 provides the most widely accepted formal definition of cloud computing:

*"Cloud computing is a model for enabling ubiquitous, convenient, on-demand network access to a shared pool of configurable computing resources (e.g., networks, servers, storage, applications, and services) that can be rapidly provisioned and released with minimal management effort or service provider interaction."*

This definition, published in 2011, remains the global standard referenced by Azure, AWS, Google Cloud, and virtually every enterprise cloud adoption framework. It describes not just *what* cloud computing is, but *how* it should work: ubiquitous access, shared resources, rapid provisioning, and minimal friction. When you study for the AZ-900 exam, understanding this definition helps you evaluate whether a given service truly qualifies as "cloud" or is merely traditional hosting rebranded.
</DeepDive>

<Callout type="tip">
For the AZ-900 exam, remember the mnemonic **"On Broad Resource Rapid Measured"** — the first word of each NIST characteristic: **On**-demand self-service, **Broad** network access, **Resource** pooling, **Rapid** elasticity, **Measured** service.
</Callout>

## How Cloud Computing Works

Behind every cloud service are three foundational building blocks working together:

**Data centers** — Cloud providers operate massive physical facilities around the world, each containing thousands of servers, storage arrays, and networking equipment. These data centers feature redundant power supplies, advanced cooling systems, and multi-layered physical security. Microsoft alone operates hundreds of data centers across these regions.

**Virtualization** — Raw physical hardware is divided into multiple virtual resources using software called a **hypervisor**. A single physical server can host dozens of virtual machines, each running its own operating system and applications as if it were a standalone computer. Virtualization is the technology that makes resource pooling and multi-tenancy possible — it's the engine of cloud computing.

**Internet delivery** — Users access cloud resources remotely through the internet using APIs (Application Programming Interfaces), web portals like the Azure Portal, command-line tools like Azure CLI, or infrastructure-as-code templates. There's no need to physically visit a data center or install specialized networking equipment — a browser and an internet connection are all you need.

## Cloud Computing vs Traditional IT

Before the cloud, organizations had to build and maintain their own IT infrastructure. Here's how the two approaches compare:

**Ownership vs rental** — Traditional IT requires purchasing physical servers and equipment outright. Cloud computing lets you rent resources on demand, converting large capital investments into smaller, ongoing operational expenses.

**Fixed capacity vs elastic scaling** — With on-premises infrastructure, you buy hardware based on your best guess of future needs. If traffic spikes beyond that capacity, your systems go down. If it stays below, you've overpaid. Cloud computing scales dynamically — you get exactly the capacity you need, when you need it.

**Weeks to provision vs minutes** — Ordering, shipping, racking, and configuring a new on-premises server can take weeks or even months. In the cloud, you can deploy a new virtual machine, database, or entire network in minutes through a web portal or command line.

**Dedicated hardware vs shared resources** — Traditional data centers use dedicated hardware for each organization. Cloud providers pool resources across many customers using virtualization, achieving efficiencies of scale that reduce costs for everyone.

<Callout type="warning">
Cloud computing is not just "someone else's computer." It's a fundamentally different operational model built on self-service provisioning, elastic scaling, and measured billing. A co-located server in a rented rack is *not* cloud computing — it lacks self-service, elasticity, and metered billing. The distinction matters on the exam.
</Callout>

## Why Cloud Computing Matters

Cloud computing has become the foundation of modern business technology. While we'll explore these benefits in depth in section 1.6, here's a preview of why it matters:

- **High availability and disaster recovery** — Cloud providers replicate your data across multiple facilities, so a single hardware failure or natural disaster doesn't take you down.
- **Global scale in minutes** — Deploy your application in data centers on every continent without building or leasing a single facility.
- **Cost efficiency through pay-as-you-go** — Stop paying for idle resources. Scale down on weekends, scale up for product launches, and pay only for what you actually consume.
- **Faster innovation cycles** — Spin up development environments in minutes, experiment freely, and tear them down when you're done — without procurement delays or wasted hardware.

<KeyTakeaways>
- Cloud computing is the delivery of computing services over the internet, enabling on-demand access to servers, storage, databases, and more without owning physical infrastructure.
- NIST defines five essential characteristics: on-demand self-service, broad network access, resource pooling, rapid elasticity, and measured service.
- Cloud computing relies on three foundations: physical data centers, virtualization (hypervisors), and internet-based delivery through portals, CLIs, and APIs.
- The consumption-based model means you pay only for the resources you actually use — like a utility bill.
- Cloud computing differs fundamentally from traditional IT through elastic scaling, self-service provisioning in minutes rather than weeks, and shared infrastructure that drives down costs.
</KeyTakeaways>
